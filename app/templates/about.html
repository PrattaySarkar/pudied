About
PUDIED

Prattay's Urban Dictionary of Interesting Engineering Decisions is a living field guide to improvisation, technical folklore, and the beautiful moment when a workaround becomes institutional knowledge.

01

What belongs here?

Improvised techniques, engineering concepts, questionable decisions, inside jokes, useful warnings, and any phrase that deserves a definition before it escapes into the workshop.

02

How it works

PUDIED discovers JSON files recursively from the data/ directory. Folders become categories, files become articles, and the index refreshes live while the app is running.

03

Add an entry

Create a JSON file with an id, title, and definition. Put it in any folder under data/; no registry, route, or frontend edit is required.
